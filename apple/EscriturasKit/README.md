# EscriturasKit

Swift package wrapping `escrituras-core` for the native macOS app. The Swift API
is generated by [UniFFI](https://mozilla.github.io/uniffi-rs/) from
`crates/escrituras-ffi`.

## Build

On a Mac with Rust installed:

```bash
scripts/build-xcframework.sh          # universal release build
scripts/build-xcframework.sh --host   # faster: this Mac's architecture only
cd apple/EscriturasKit && swift test
```

The script writes `EscriturasFFI.xcframework` and `Sources/EscriturasKit/Generated/`
(both gitignored). Re-run it after changing `crates/escrituras-ffi` or core.

## Use

```swift
import EscriturasKit

let library = try Library.open(dataRoot: resourcesURL, studyDatabase: studyDBURL)
let verses = library.verses(book: "Alma", chapter: 32)
let results = library.search(query: "faith", limit: 20)

final class Printer: ReplyListener {
    func onDelta(text: String) { print(text, terminator: "") }
}
let reply = try await library.ask(
    provider: .claude, model: "claude-opus-5-5", apiKey: keyFromKeychain,
    history: [Message(role: .user, content: "What is faith?")],
    context: StudyContextInput(currentReading: "Alma 32", browsedChapters: [], includeSavedVerses: true),
    listener: Printer()
)
```

`dataRoot` is a directory containing `lds-scriptures-2020.12.08/` and,
for search by meaning, `data/`.
