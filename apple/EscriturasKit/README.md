# EscriturasKit

The native macOS app and the Swift package it's built on (macOS 14+).

- `EscriturasKit`: Swift bindings for `escrituras-core`, generated by
  [UniFFI](https://mozilla.github.io/uniffi-rs/) from `crates/escrituras-ffi`
- `EscriturasApp`: the app's models (`AppModel`, `ChatModel`) and SwiftUI views
- `Escrituras`: the app's entry point

## The app

- Three columns: volumes and books, chapters (or search results), and the reader
- Search in the toolbar (⌘F); Return opens the first result and moves to the
  results, where ↑/↓ open each one; Escape leaves search. ⌘L goes to a
  reference such as `Alma 32:21`
- The inspector (⌥⌘I) holds saved verses, notes, and AI chat
- Go menu: Back/Forward (⌘[ ⌘]), previous/next chapter (⌥⌘← ⌥⌘→)
- Verse menu: Save (⌘D), Add Note (⌥⌘N), Copy (⇧⌘C), Ask About This Verse (⇧⌘A)
- Keyboard navigation, as in NetNewsWire: ← and → move between the columns
  (→ or Return in the books opens the book, in the chapters it enters the reader),
  ↑/↓ move through books, chapters or verses, continuing into the next or
  previous chapter past the ends of one; Home/End jump to the first/last verse
- Settings (⌘,): text size, AI provider and model, API keys (stored in the Keychain)
- Saved verses, notes and the reading position are in
  `~/Library/Application Support/escrituras/study.db`, shared with the terminal app

Launch arguments open a particular state, e.g.
`Escrituras -Open "Alma 32:21" -ShowInspector YES -InspectorTab ask` or `-Search faith`.

## Build

On a Mac with Rust installed:

```bash
scripts/build-xcframework.sh          # universal release build
scripts/build-xcframework.sh --host   # faster: this Mac's architecture only
cd apple/EscriturasKit && swift test
scripts/build-mac-app.sh              # target/Escrituras.app with the data bundled
```

To work on the app, open `Package.swift` in Xcode and run the `Escrituras` scheme
(it finds the scripture data in the repository checkout).

The script writes `EscriturasFFI.xcframework` and `Sources/EscriturasKit/Generated/`
(both gitignored). Re-run it after changing `crates/escrituras-ffi` or core.

## Use

```swift
import EscriturasKit

let library = try Library.open(dataRoot: resourcesURL, studyDatabase: studyDBURL)
let verses = library.verses(book: "Alma", chapter: 32)
let results = library.search(query: "faith", limit: 20)

final class Printer: ReplyListener {
    func onDelta(text: String) { print(text, terminator: "") }
}
let reply = try await library.ask(
    provider: .claude, model: "claude-opus-5-5", apiKey: keyFromKeychain,
    history: [Message(role: .user, content: "What is faith?")],
    context: StudyContextInput(currentReading: "Alma 32", browsedChapters: [], includeSavedVerses: true),
    listener: Printer()
)
```

`dataRoot` is a directory containing `lds-scriptures-2020.12.08/` and,
for search by meaning, `data/`.
